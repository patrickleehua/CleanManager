## 推荐体验路径

1. **Agent 交接：**Agent → 第一条请求“查看” → 模拟 CLI 调用。看到退出 3 / needs_approval 后，打开“计划”审阅同一 ID。改变处理方式会生成新 ID、不同演示摘要并重置批准。
2. **已有授权：**刷新原型 → Agent / 有限策略 → 启用演示策略 → 模拟匹配 → 查看同一计划 → 按已有授权执行。3 个固定样例共 64 MiB；示例累计用量从 512 到 576 MiB，不再索取逐次批准。
3. **额度不足：**有限策略 → 体验余额不足 → 模拟匹配。请求转为需人工审阅，系统不把范围外或超限对象自动加入策略。
4. **中断核对：**设置 / 演示场景选“中断”后走第 2 条路径。退出 8，结果 unknown，未知对象额度暂保留；只读核对源/目标、确认示例未执行后，额度从 552 降为 528 MiB，已成功的 16 MiB 仍计入。重复提交返回已有 partial 报告及退出 5，不重复动作。
5. **规则联动：**规则与依据 → 编辑器规则 → 暂停演示规则 → 应用。Code Cache/GPU Cache 变为不可选，相关旧计划执行时按变化条件判断。
6. **恢复冲突：**恢复 → 选 report.cache → 恢复计划。原位置冲突时保留两份内容；选择其他位置后生成独立恢复计划，审阅页展示恢复目标。
7. **覆盖与平台：**扫描记录查看未读范围；进入平台能力，切换 macOS/网络目录/读取拒绝，查看不同能力的解释。这里不修改真实系统权限。

刷新会重置演示请求、计划、规则、额度和恢复数据；只有主题沿用原型的本地偏好保存。所有候选、身份、路径、时刻和大小均为合成样例。
