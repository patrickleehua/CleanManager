# CleanManager v5 · AI 诊断原型

更新：2026-10-15。在 v3.4 / v4 的 Mole 风格 HTML 上增加可选 AI 诊断，保留现有底色、字体、主题变量、导航、侧栏、弹窗与计划流程。原 app.js、style.css、features-v4.js/css 保持原版本；新增 ai-diagnostics-v5.js/css，由 index.html 顺序加载。

入口：[AI 诊断](http://127.0.0.1:8765/suite-v3/?v=5.0#diagnosis)。也可从磁盘、清理候选和应用详情点击“AI 诊断”，或通过快捷搜索“能不能删”“用途”“API”进入。“AI 数据”仍管理工具缓存/会话/模型空间，与诊断分开。

## 体验路径

1. **首次配置与预览：**工作台 → Code Cache → 配置接入 → 自配 API 或已有 CLI → 保存样例配置。默认预览脱敏元数据；可选择完整路径和最多五个匿名子项摘要。取消预览不会新增诊断。
2. **缓存交接：**开始诊断后看用途、删除影响、重建方式和依据 → 核验并生成计划。只有 Code Cache 一项 160 MiB；批准仍未勾选，执行按钮禁用。重复交接返回同一份未过期计划。
3. **未知大文件：**磁盘分析 → Downloads → 素材视频.mov → AI 诊断。无需已匹配规则；回答提示备份/工程引用，用户补充“已备份”仍是未核实陈述。可继续问恢复条件、查看核实清单、定位或保留。
4. **安装包与模型：**工作台选择安装包，了解离线安装/修复/重新获取条件；选择 Models，了解依赖、离线和共享块未知，并查看模型管理指引。不会把逻辑大小直接说成可释放空间。
5. **取消与故障：**右侧“诊断信息与演示”展开后，选择保持运行、超时或无效回答，再选择对象或重新预览。导航不取消；主动取消进入明确终态。失败没有计划入口。
6. **资料过期：**缓存回答 → 诊断信息与演示 → 模拟对象资料变化。旧解释保留，生成计划按钮关闭；重新诊断会再次预览对象资料。
7. **接入与记录：**设置 → AI 诊断接入，可配置/移除样例配置。接入变化后，对旧诊断追问要求重新预览。移除诊断记录不移除已经生成的计划。记录列表展示最近六条；保留标记也只在本次浏览器会话有效。

## 规格追踪

| 交互 | 行为要求 |
| --- | --- |
| 未配置/移除接入、本地功能继续使用 | AID-01 |
| 候选、未知大文件、目录与应用详情入口 | AID-02 |
| 判断依据、用户陈述和推测分层 | AID-03/04/05 |
| API/CLI 配置、无文件探针概念、不可约束 CLI 状态 | AID-06/08/12 |
| 实际载荷预览、脱敏、单独选择完整路径/子项 | AID-07 |
| 单对象计划、保留/定位/核实/应用管理指引 | AID-09 |
| 导航持续、取消/超时/无效/过期 | AID-10 |
| 一致主题、键盘入口、窄窗口 | AID-13 |

AID-11 的真实诊断 CLI/Agent 契约、模型适配、凭据存取与真机验收属于产品实施任务，不由 HTML 原型冒充。完整规划为 [13 条要求 / 19 个场景](../../../openspec/changes/define-cleanmanager-mvp/specs/ai-cleanup-diagnostics/spec.md) 与 [9 个可选扩展任务](../../../openspec/changes/define-cleanmanager-mvp/tasks.md)；9 项首版能力及其 G0/G1/G2 范围保持原定义。
