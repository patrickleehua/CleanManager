## 查看

直接在浏览器打开同目录的 `index.html`，无需安装依赖。也可通过本地 HTTP 服务查看。左侧切换 16 个页面/状态，支持整组图、单页图、放大、左右方向键和下载原图。点击“体验交互”打开对应流程演示。

图像由内置 image_gen 生图模型生成；不是 HTML 截图替代品。完整生成提示词保存在 `prompts.json`。HTML 提供图片浏览和可操作的交互层，图片本身是静态设计稿，不是每个图内按钮都有热点的完整应用。

## 交互

- 扫描：选根 → 开始 → 取消保留结果，或查看已有结果。
- 清理：默认无选中 → 手动选组 → 生成计划 → 选择模式 → 人工勾选审阅 → 执行。改变模式清除旧审阅选择。
- 执行：固定对象进度 → 停止后续处理 → 保留成功/未开始结果。
- 恢复：原位置冲突 → 保留双方，或另选位置生成独立恢复计划。
- Agent：审阅同一计划 → 人工授权；过期重新生成。
- 中断：未知副作用 → 只读核对，不提供自动重放。
- 策略：默认关闭 → 主动启用 → 精确根、规则版本、模式、单次/累计额度。

UI 采用短标签、表格、页签、抽屉、少量关键提示和单个主操作，减少长段说明。深层解释通过按需展开呈现。键盘焦点清晰，危险状态带文字。

## 设计稿核对

这些都是演示数据和拟议界面，不代表产品实现或平台验收。图片生成会出现局部文字/数字偏差：01 中未知空间不能在真实产品中凭空计算；云下载开关在 MVP 应固定关闭；02 中空选择“预计释放 0 B”应在实现时改为“未选择”；示意规则不能据应用名、目录名或访问时间直接认定可删；过期计划不能执行或原地切换永久删除，应生成新计划并重新授权；图中计划时刻/数量是示意，不是协议样例。可操作 HTML 流程遵循审阅、模式改变清除确认和独立恢复授权的边界。

已验证交互：默认选择禁用生成计划；选择后可生成；未审阅时不可执行；审阅后可执行；模式改变重置审阅；恢复冲突默认不覆盖；有限策略默认关闭。最终图像文件和页面引用应一并保留。
