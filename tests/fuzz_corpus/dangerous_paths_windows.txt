# lines are NOT trimmed. Escapes: <EMPTY> is the empty path; <U+XXXX> (4-6 hex digits) is that
# code point, or a lone UTF-16 code unit for D800-DFFF. "LINK => TARGET" declares that LINK is a

# separators, trailing dot/space, \?\ prefix); any Allowed result fails CI.
