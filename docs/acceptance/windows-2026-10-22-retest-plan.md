# BUG-WIN-01 修复后的 Windows 复验计划

原始依据与失败证据：[用例 WIN-09](windows-2026-10-22-cases.md)、[首次验收报告](windows-2026-10-22-report.md)。修复由用户明确授权的 subagent 实施；主 agent 独立复验。历史失败记录保留，不修改原预期。

被测版本将记录为 `2d654d9` 加本次未提交补丁，并保存实际二进制 SHA-256。复验前重新构建 CLI 与 Windows 桌面，使用独立存储、原始夹具及独立清单；不批准或执行文件移动、删除、恢复或系统变更。

| 标识 | 前置与操作 | 独立预期 |
| --- | --- | --- |
| RT-01 | 对 1,024 字节普通文件 a.txt 执行 scan，再查询该 scan 的 entries | 明确非目录原因，failed/error；无 partial、无伪目录条目，输入不变 |
| RT-02 | 对 0 字节文件 nested/zero.txt 执行相同操作 | 同样拒绝，不能将真实空文件混同于空目录 |
| RT-03 | 对 2,048 字节中文空格名文件执行相同操作 | 同样拒绝；错误准确定位原始路径，无字符损失 |
| RT-04 | 扫描不存在的目录 | 维持 failed / root_unavailable，不回退到其他范围 |
| RT-05 | 扫描原始普通目录和 empty 空目录 | 普通目录 completed、10 条目、27,904 字节；真实空目录 completed、0 文件、0 字节，无错误 |
| RT-06 | 对正常扫描做两项分页、中文过滤、空过滤、非法页大小查询 | 十条全部无重无漏；中文仅一条；不存在词为空；非法大小明确拒绝，字节保持字符串/null |
