- 桌面用例在 Tauri 原生 Windows 窗口执行；CLI 用例运行从同一提交构建的二进制，明确记录两者覆盖层次。
- 真实磁盘/应用只读清单与受控文件扫描分别记录；不触发用户目录全量扫描。
- 不通过修改产品或降低预期消除失败。新发现的问题记录复现、影响和证据，修复需要另行授权。
- 仅为本次验收保存证据与可复跑的临时执行脚本，不新增测试框架；执行状态独立于业务用例。
