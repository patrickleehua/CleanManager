# Proposal

## Why

用户需要一个 Windows/macOS 通用的磁盘清理与管理工具，既能像 Mole 一样方便人工维护、像 WizTree 一样定位空间去向，也能通过 CLI/Skill 供 Claude/Codex 调用。当前仓库已有研究、设计与合成契约，尚无产品实现；需要把这些材料转成可验收的首版需求，使人工和 Agent 共用一致的扫描事实、操作计划与结果。

## What Changes

- 建立 Rust 共享核心和独立 CLI，桌面采用 Tauri 2/TypeScript；业务规则、索引、授权和执行不依赖窗口。
- 提供双平台范围明确的只读扫描、目录/大文件分析、分页查询、空间统计和能力说明；Windows/macOS 使用各自的原生后端，性能以同口径实测确认。
- 引入少量有来源与真实平台验证的清理规则，解释风险、再生成影响与保留理由。
- 建立不可变操作计划、可信人工授权或有限预授权、实时身份核验、跨进程互斥、逐项日志与中断核对。
- 支持已验证范围内的同卷隔离、平台回收站及明确授权的永久删除；提供隔离恢复、冲突处理与历史。空间报告区分处理量、估计释放和卷空闲观测。
- 提供机器可读 CLI 和配套精简 Skill 工作流，允许 Agent 与人工查看、交接同一计划；CLI 可单独安装和运行。
- 提供概览、磁盘 treemap/目录表、候选与计划、只读应用清单、执行历史、隔离恢复和设置等桌面入口。
- 定义可选的 AI 清理诊断扩展：用户自配 API 或已有 CLI，从候选或任意已扫描大文件发起，解释用途、依据、删除后果、不确定性及更稳妥的下一步；AI 建议不构成执行授权。
- 按只读验证、核心闭环、桌面发布分阶段实施。后续范围包括增量索引、来源明确的卸载/维护、更多规则、TUI、MCP 和可选 WizTree CSV 导入；本次不实现通用 shell 插件、注册表/内存加速或任意路径递归清理。

## Capabilities

### New Capabilities

- `disk-scanning`: 指定范围的只读枚举、平台能力、部分结果、取消与统计口径。
- `disk-index-query`: 版本化索引、目录/大文件分页、排序过滤、大小与完整性汇总。
- `cleanup-analysis`: 声明式规则、应用归属证据、保护项、解释与候选去重。
- `operation-plans`: 固定对象计划、摘要、有效期、人工授权和有限预授权策略。
- `operation-execution`: 实时核验、受限执行、冲突/重复请求控制、逐项日志及中断核对。
- `recovery-history`: 隔离与恢复清单、目标冲突、独立清空计划、执行历史与空间报告。
- `agent-cli`: 独立命令、版本化 JSON/JSONL、退出语义、可信人机入口、精简 Skill。
- `application-inventory`: 来源可追溯的只读应用清单、关联目录与共享/未知归属。
- `desktop-management`: 人工扫描/审阅/执行/恢复旅程、可访问的磁盘可视化与跨入口一致性。
- `ai-cleanup-diagnostics`: 可选扩展；对象级诊断、必要信息预览、用户自配 API/CLI、依据与追问、受核心核验的行动交接。独立于首版九项能力的 G0/G1/G2 验收。

### Modified Capabilities

无。项目当前没有 main specs；本变更为首次产品行为基线。

## Impact

- 后续新增 Rust workspace、平台适配、SQLite 索引/审计存储、CLI、桌面应用、契约测试与受控平台夹具；本次 propose 仅创建规划工件。
- 补全现有 `schemas/v1` 的列表、运行态、扫描取消、人机授权和恢复等缺口；现有样例为草案，不假定已有外部兼容负担。具体版本与扩展由契约评审冻结。
- 首版验收需要真实 Windows 及 Mac、平台权限与签名/安装/更新验证。优先验证 Windows 11 x64 和 Apple Silicon；最低系统版本和更多 CPU 架构由证据确定。
- 复用 `docs/` 作为研究与设计依据，不复制 Mole/WizTree 的品牌或闭源实现，不默认捆绑第三方二进制。
- 本次提案不宣称已有秒扫性能、完整磁盘访问、已通过产品测试或任意目录零竞态清理能力。
- AI 扩展另列任务与发布验收；配置缺失或服务不可用不阻止本地功能。本轮更新交付规格与 HTML 交互原型，不接通模型、保存真实凭据或新增任意路径删除能力。
