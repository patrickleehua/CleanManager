# Tasks

全部产品实施任务未执行。依据为 [design](design.md) 和 [9 项首版能力 + 1 项可选 AI 扩展](proposal.md)。HTML 原型和规格已设计不等于以下产品任务完成。编号与 `docs/roadmap.md` 的 TASK-* 研究路线编号不是同一命名空间。

实施顺序：1–6 形成 G0 只读基线；7–10 形成 G1 受限写/恢复核心；11–14 形成 G2 桌面首版。CLI 的只读部分可随核心提前接入；规则、计划、授权的数据模型可在等待设备时先做无目标写入的单元验证。原生写能力和发布不得跨过相应平台/规则门禁，缺 Mac 不冒充双平台通过。

15 为独立可选扩展，不阻塞九项首版能力验收；不得把“AI 建议”计作规则验证或用户授权。
